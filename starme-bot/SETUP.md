# Как запустить — по шагам (просто)

Боту нужны **две вещи**:

1. **Дом** — компьютер или сервер, где bot будет жить и общаться с Telegram (24/7).
2. **Мозги** — нейросеть, которая делает фото. Легче всего — Replicate (бесплатные $10 на старте, дальше копеечки).

## Шаг 1. Получить «мозги» (Replicate)

1. Зайдите на [replicate.com](https://replicate.com), зарегистрируйтесь.
2. Откройте [replicate.com/account/tokens](https://replicate.com/account/tokens) и создайте токен (одна кнопка).
3. Скопируйте токен — он похож на `r8...`.

## Шаг 2. Запустить bot

### Вариант А — на своём компьютере (для проверки)

Нужен [Node.js](https://nodejs.org) (версию 20+).

Сначала проверим, всё ли подходит:

```bash
cd starme-bot
npm install
npm run check      # покажет, подходит ли комп и есть ли доступ к Telegram/Replicate
```

Если все ✅ — продолжайте.

Создайте файл `.env` (переименуйте `.env.example`) и заполните:

```
TELEGRAM_BOT_TOKEN=...      # токен бота из @BotFather
STARME_GENERATOR=replicate
REPLICATE_API_TOKEN=r8...
```

Запустите:

```bash
npm start
```

Главное ограничение: компьютер должен быть включён, чтобы bot работал. Для личного использования и тестов — нормально.

### Вариант Б — на сервере (24/7)

Для настоящей работы bot должен быть в сети всегда. Дешевый VPS стоит ~$4–6 в месяц. На сервере нужны те же шаги (Node.js + `.env` + `npm start`), плюс bot можно положить в фон (например, `pm2`).

## Шаг 3. Проверить

Откройте бота в Telegram, отправьте:

1. Фото знаменитости → bot разберёт сцену и попросит селфи.
2. Своё селфи → получите персональное фото.

Команды: `/status`, `/template` (показать дизайн-код), `/reset`.

## Что без Replicate?

- `STARME_GENERATOR=mock` — работающий пайплайн без нейросети (для знакомства с bot).
- `facefusion` — бесплатно и локально, но нужен GPU.
- `instantid` — генерирует сцену по дизайн-коду, нужен GPU.

## Декларация

StarMe AI делает deepfake-подобный контент (лицо человека на сцене). Будьте готовы к вопросам согласия, конфиденциальности и правил платформы/юрисдикции.
